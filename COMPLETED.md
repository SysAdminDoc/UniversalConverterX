# UniversalConverterX Completed Work

This file summarizes shipped work. Release-level detail remains in
[`CHANGELOG.md`](CHANGELOG.md); open work remains in [`ROADMAP.md`](ROADMAP.md).

## Current Release

UniversalConverterX is at **v2.21.0** on `main`.

## Shipped Product Surface

- WinUI 3 / .NET 10 Windows shell with Converter, Compressor, Editor,
  Downloader, Recorder, Toolbox, history, watch-folder, presets, and CLI
  surfaces.
- Core conversion engine with FFmpeg, ImageMagick, libheif, libjxl, libvips,
  Inkscape, Calibre, Pandoc, Ghostscript, LibreOffice, Assimp, resvg, Potrace,
  and related format backends.
- NDJSON sidecar architecture with roughly 180 specialized tools across media,
  documents, archives, subtitles, OCR, AI, forensics, CAD, GIS, science,
  developer, enterprise, and long-tail format families.
- Preset browser, right-click preset flow, shell extension, PowerShell module,
  REST service, history dashboard, watch-folder service, VMAF analysis, scene
  detection, timeline preview, and structured local diagnostics.
- v2.21.0 shipped parallel job limit enforcement, DPAPI cookie-encryption
  infrastructure, and a broad premium UI polish pass across 23 WinUI pages.

## Shipped Milestones

- **v1.x:** native converter, CLI, shell extension, and first UI.
- **v2.0 - v2.4:** Wondershare-style shell, sidecar contract, compressor/editor/
  downloader integration, recorder/account surfaces, REST/PowerShell/history,
  watch folders, VMAF, and accessibility pass.
- **v2.5 - v2.20:** broad format-coverage waves across documents, archives,
  subtitles, AI, science, GIS, healthcare, finance, engineering, media, dev,
  and specialty enterprise formats.
- **v2.21.0:** roadmap items 99 and 100 plus premium UI polish and version sync.
