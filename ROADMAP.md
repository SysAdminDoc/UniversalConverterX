# UniversalConverterX — Product Roadmap

**Status:** v2.22.0 · 190 sidecar engines · 290+ presets · 45+ UI pages
**Last updated:** 2026-07-01

Blocked items live in [`Roadmap_Blocked.md`](Roadmap_Blocked.md).
Shipped work is recorded in [`CHANGELOG.md`](CHANGELOG.md).

**Design charter:** Offline-first. No cloud. No accounts. No telemetry.
Windows 10 21H2+. Beat every competitor on: format coverage, batch UX,
programmability (CLI + REST + PS module), and AI depth.

## Tier 2 — Next _(v2.23–v2.27)_

### 26. WinAppSDK 2.0 Migration

Upgrade from WinAppSDK 1.x to 2.0. Key gains: `SystemBackdropElement` (in-app Mica/Acrylic panels), `Microsoft.Windows.Storage.Pickers` (file type grouping), `IXamlCondition` (parse-time feature flags). **Caveat:** WinAppSDK 2.0 bundles ONNX RT 1.24.5, below UCX's ≥1.25.1 floor — Python sidecars keep their own pin. Breaking changes: review `DispatcherQueue` API surface and `AppWindow` interop.

> **2026-07-16 research note:** Already done in substance — `UniversalConverterX.UI.csproj` references `Microsoft.WindowsAppSDK` **2.2.0**. Close this item after verifying the 2.x API adoptions above; blocked Item 64 (SystemBackdropElement, `Roadmap_Blocked.md`) is now unblocked.

Impact: 3 · Effort: 3 · Type: platform

---

### 28. FFmpeg 8.x Sidecar Refresh

Audit all FFmpeg-dependent sidecars. Pin to ≥7.1 (current stable), test against 8.1 "Hoare". Notable 8.x gains: D3D12 encode/filter pipeline, Vulkan ProRes, libavcodec 62.x. Carry a pinned FFmpeg build in `tools/ffmpeg/`.

> **2026-07-16 research note:** Urgency escalated — CVE-2026-8461 "PixelSmash" (MagicYUV heap OOB → RCE via crafted AVI/MKV/MOV, CVSS 8.8) is fixed only in **8.1.2**; 21 further disclosed zero-days are rolling into 8.1.x point releases. The floor for this item is now ≥8.1.2, and Item 99 adds a runtime version gate.

Impact: 3 · Effort: 2 · Type: platform + security

---

### 29. Manual FFmpeg Command Override (Advanced Mode)

Expose the FFmpeg command generated by each sidecar in a read-only "Advanced" panel. Add an opt-in "Edit before run" toggle that lets power users modify the argument string before dispatch. Input sanitized: disallow shell injection characters. Disabled by default; enabled via Settings toggle. No new sidecar required.

Impact: 4 · Effort: 3 · Type: leapfrog

## Tier 3 — Later _(v2.27+)_

### 37. Auto Highlight — Scene Detection + Clip Extraction

Analyze video for scene-change peaks and motion energy; auto-extract highlight reel. Backend: FFmpeg `select=scene` + PySceneDetect. Export scene list as EDL (CMX 3600) or OTIO. Pin `PySceneDetect>=0.6.7` for correct EDL timestamps.

Impact: 3 · Effort: 4 · Type: leapfrog

---

### 40. Chapter Editor (MKV / MP4)

Add/edit/delete/import/export chapter markers without re-encoding. Backend: `mkvmerge --chapters` for MKV; FFmpeg for MP4. Pin `mkvmerge ≥ v97.0` for TrueHD-in-MP4 read support. Preserve exact PTS values during import.

Impact: 3 · Effort: 3 · Type: parity

---

### 41. Localization (i18n / l10n)

Extract all user-visible strings into `Resources.resw` per-language files. Priority locales: DE, FR, ES, PL, ZH-Hans. Large cross-cutting change (all 45 XAML pages + Core messages).

Impact: 4 · Effort: 5 · Type: i18n
